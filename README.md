## Example

A simple tuple:

```python
t1 = (3, 14, 6, 3, 9, 3, 5, 3)

print(t1)
print(t1[0])
print(t1[-1])
```

Example of `count()`:

```python
print(t1.count(3))
```

Example of `index()`:

```python
print(t1.index(14))
```

Example of `max()`, `min()` and `sum()`:

```python
print(max(t1))
print(min(t1))
print(sum(t1))
```
